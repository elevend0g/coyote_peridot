## What is this?

**Coyote Peridot** is a self-contained adventure module for **Base10**, a tabletop RPG system. It's built as an onboarding module within the larger **Continuum11 / Frame 2 Reality** setting — a complete, five-level dungeon-crawl-style expedition that doubles as a soft introduction to Base10's core mechanics (Attributes, Skills, Chaos Rolls, Combat Exchanges, Power Tiers).

The premise: the party's ship clamps onto the hull of a vast, ancient, derelict station — Coyote Peridot — that has never had a single visitor. Four competing factions have each sent (or hired) a crew to reach the Station's Core. The party is one of those crews. What's inside is watching back.

This repository holds the **playtest materials** for the module — character creation rules, Skills and Professions, starting gear, and the Custodian-facing (GM-facing) encounter and loot tables for running the five levels. Several sections are explicitly marked as draft/in-review (see [Status](#status--known-gaps) below); this is a working playtest package, not a final print product.

## Setting at a glance

- **The Station:** Coyote Peridot, an enormous structure that has run for millennia without human presence. It is observing the party as much as the party is exploring it — an "Interface" tracks behavior across the whole expedition.
- **The Factions:** four competing interests, each a valid starting affiliation for any character, regardless of Profession:
  - The Corporation — own it, extract it, monetize it
  - The Mercenary Company — contracted professionals, terms undisclosed
  - The Privateer — first claim, finder's fee
  - The Scientific Institution — understand it, preserve it
- **The Levels:** five areas, each tied to a Power Tier, each ending in a boss fight:
  1. **Agricultural** (P1)
  2. **Residential** (P2)
  3. **Commercial** (P3)
  4. **Scientific** (P4)
  5. **Industrial / Core** (P5) — the Maze and the Interface; the Final Encounter
- **The throughline:** a running "Core Tracking" tally built from how the party resolves encounters (fighting vs. talking, forcing vs. adapting). It never blocks progress — only death does — but it shapes how the Station's Interface responds at the end.

## Quick orientation for a new reader

- **Starting a character?** Begin with the Character Creation Guide — it references Skills.md and Professions.md at the relevant steps, and Starting Equipment for gear catalogs.
- **Running the table?** The Hull Breach encounter is the opening scene, resolved before Level 1 formally starts. From there, each Level pairs an Encounter Table Stage with its matching Room Loot Table (roll both independently per room) and uses the Mob Drop Table from Starting Equipment whenever a notable hostile is defeated.
- **Core mechanics** (Chaos Rolls, Exchanges, Power Tiers, Advancement Points, Kit/mod slots) belong to the base **Base10 System Guide**, which is referenced throughout but not included in this repo — these documents define Coyote Peridot's content *within* that framework, not the framework itself.

## Status / known gaps

This is a **playtest** package — several things are explicitly flagged in the source documents as unresolved:

- **Starting armor** has no official home yet in Professions.md; a stopgap table lives in the Character Creation Guide pending integration.
- The **Skill Gear table** in Starting Equipment lists "Combat" as a skill option, but the Core Skill Tier used elsewhere is Physique, not Combat — needs reconciling.
- Several **Profession Class Features at P4/P5** (Shadow, Soldier, Tech, Medic) have Passive Effects marked as draft, pending precise trigger language and Custodian-adjudication rules.
- The worked example character "Zero" is new to this module and only shares a name with the Base10 System Guide's own example character (built on different, non-Coyote-Peridot content) — not the same character.

Feedback from playtesting should focus on these gaps as well as general balance and pacing across the five Levels.
