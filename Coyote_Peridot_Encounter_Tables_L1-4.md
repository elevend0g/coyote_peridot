# Coyote Peridot — Level Encounter Tables (Custodian Reference)

*Two independent d10 encounter tables per level — Room A and Room B — for the Agricultural, Residential, Commercial, and Scientific levels. Every room follows the same standardized mix: 2 Wave, 3 Skill, 3 Combat, 2 Hybrid, interleaved so the same type never lands twice in a row. Station-flavored and Human-faction encounters are blended within each room rather than segregated by type.*

---

## Legend

| Tag | Type | Resolution |
| :-: | :--- | :--- |
| **C** | Combat | Standard Standoff → Exchange → Repeat. |
| **S** | Skill Challenge | Successful 2 out of 3 Chaos Rolls against the listed Skill(s).  |
| **H** | Hybrid | Skill checks first; any failure escalates into Combat. |
| **W** | Wave | Automatta spawn a fresh unit(s) at the start of every Standoff. The wave does not stop on its own. Someone must find and successfully act on the encounter's off/on switch (console, valve, breaker, root node) via the listed Skill. Once thrown, spawning ends and the current Exchange plays out to resolution. The number of Automatta spawned is equal to the Power Tier of the encounter.  |

A character can make only ONE Chaos Roll per skill in the encounter. NO EXCEPTIONS.                

Skills referenced: **Perception, Adaptation, Composure, Stealth, Combat, Medicine, Influence** (Core Tier 7). Every room below totals exactly 2 W / 3 S / 3 C / 2 H.

### Tracked Consequences

No result on these tables ever block the party from moving forward. The only outcome that stops the adventure short of the Final Encounter is death. Everything else is a running tally the Interface reads at the Core.

| Result | Notes | Score |
| :--- | :--- | :-: |
| Skill Challenge succeeds | "Excellence is not an act, but a habit." | **-1** |
| Skill Challenge fails | "Weakness of attitude becomes weakness of character." | **+1** |
| Hybrid resolved through the Skill (no escalation) | "Blessed are the peacemakers" | **-1** |
| Hybrid escalates into Combat | "Violence is the last refuge of the incompetent" | **+1** |
| Wave ends in anything short of a party death | "That which does not kill us makes us stronger" | **-1** |
| Combat does not end in party death | "Once more unto the breach, dear friends" | **+1** |

Keep a running total for the adventure. If the party decides not to or cannot complete a Skill Challenge, it counts as a fail. During a Hybrid encounter, if the party skips the Skill Chaos Rolls and chooses violence, treat as a pure combat encounter. During the final encounter, Core will use the final total to determine the outcome (see the Final Encounter section).
